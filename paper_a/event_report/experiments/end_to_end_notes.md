# Local in-process report-path experiment

`end_to_end.log` is generated by `prototype/end_to_end_benchmark_test.go` with `EVENT_END_TO_END_RUNS=30`. The experiment uses the full ActiveCircuit and ActiveGateway with one generated Groth16 setup and one warm-up. A fresh synthetic challenge, distinct participant secret and independently sampled identity point are used per attempt. Of 256 active-tree entries, 31 correspond to the warm-up and measured software fixtures; the other 225 are synthetic placeholder digests. The policy has 256 discrete cells and the signed event is synthetic.

The stages are measured sequentially using a monotonic clock: issue a gateway challenge; encrypt with ML-KEM-768, HKDF-SHA256 and AES-256-GCM; have the software fixture sign the credential, issuer authorization, event receipt and identity link and build the witness; generate and serialize a Groth16 proof; then call the gateway to reconstruct public inputs, verify the proof, authenticate/decrypt the envelope and perform in-memory deduplication. The `total_to_accept_ns` interval spans these stages including ordinary local call overhead; `audit_open_ns` measures opening the in-memory record previously accepted by the gateway; it is reported separately and excluded from total-to-accept, and does not include a separate proof re-verification or identity-registry lookup. The fixture reissues signatures which could be pre-issued in a different design; this is an observed synthetic workload, not a claim about production issuance. Compilation, one-time setup, initial fixture/key creation, policy-tree construction, credential enrollment, external transport, synchronization, real acquisition, disk persistence, distributed operation and network latency are excluded from per-report times.

The 40-byte synthetic report is sealed to an envelope whose actual serialized length is logged. Proof bytes use gnark `WriteTo`. For component-size accounting, the API's nonce is encoded as its 64-byte hexadecimal string, the nullifier as a 32-byte field encoding, and two identity-cipher points are each compressed with gnark's native `Bytes`. The sum of the envelope, proof, nonce, nullifier and compressed identity ciphertext is not an actual wire packet: framing, protocol headers and task configuration are not included. The separately reported serialized public witness is produced locally and is excluded from that sum. The experiment demonstrates the measured software path and does not prove physical location, report authenticity, or a production service-level latency.

Run in the `prototype/` directory with suitable module access:

```sh
EVENT_END_TO_END_RUNS=30 go test -run '^TestEndToEndExperiment$' -count=1 -timeout=30m -v > ../experiments/end_to_end.log 2>&1
```
